# 第64回 福岡県小学校理科教育研究大会（筑豊大会）公式サイト

2026年12月4日（金）・飯塚市立菰田小学校で開催する県大会の案内サイト。
GitHub Pagesで公開する（1ページ構成・ビルド不要の素のHTML/CSS/JS）。

## 更新のしかた（Claude Codeでの定型作業）

### お知らせを足す
`index.html` の `<!-- ▼お知らせの追記はこの下に1行コピペ -->` の直下に1行足す（新しいものが上）。
タグは「大会」「資料」の2種類。

```html
<li><time>2026.10.01</time><i class="tag">資料</i><span>本文</span></li>
```

### 参加申し込みフォームをつなぐ
`index.html` の参加申し込み節にある `<a class="btn-main" href="junbi.html">` の `href` を
フォームのURLに差し替え、`target="_blank" rel="noopener"` を足す。下の一文（準備中の案内）も消す。
つなぐまでは `junbi.html`（準備中ページ）へ飛ぶ。

### CSSを直したとき
`index.html` と `junbi.html` の `style.css?v=20260829a` の日付部分を新しくする。
これをしないと、前に見た人のブラウザが古いCSSを使い続ける。

### 水彩の素材を差し替える
すべて `assets/img/` に `.webp` で入っている（野々宮すみれの水彩・紙白を透過に焼き込み済み）。
同じファイル名で置き換えれば差し替わる。

| ファイル | どこに出るか |
|---|---|
| `hero.webp` | トップの絵（控え＝`hero_b.webp`） |
| `km_news_kami.webp` ほか `km_*_*.webp` | 各セクションの見出しの右の小さな絵 |
| `km_unit_g3〜g6_*.webp` | 学年タブの公開授業カードの挿絵 |
| `km_band_rikashitsu.webp` | 公開授業の前の横長の帯 |
| `km_band_gakko.webp` | 会場・アクセスの前の横長の帯 |
| `km_footer_futaba.webp` | フッターの双葉 |

新しい水彩を足すときは、原本PNGを
`~/Desktop/LiFE with/17 素材集/scripts/melt_to_paper.py <png> --out <出力先> --w <幅>`
に通してから置く（紙白が透過に焼き込まれ、縁が紙に溶ける）。

### PDF資料を足す
1. `pdf/` にPDFファイルを置く（例：`pdf/niji-annai.pdf`）
2. `index.html` の資料ダウンロード節でカードの `href` を差し替え、
   `class="doc-btn pending"` → `class="doc-btn"` にして、ボタン文言を「ダウンロード（PDF）」にする
3. カードを増やすときは `.doc-card` を1つコピー

### トップの水彩を差し替える
`assets/img/hero.webp` を置き換えるだけ（1200×800・背景は透過に焼き込み済み）。
控えの案b＝`assets/img/hero_b.webp`。原本と加工前PNGは `17 素材集/generated_kentaikai-hero_2026-08/`。
